# Narrated presentation material

This folder contains the source material for narrated and Google Vids versions.

- `narration.md` contains the longer spoken script.
- `google-vids-scripts.md` contains shorter scene scripts and cloud links.
- `custom-avatar.md` records the presenter-avatar direction.

The current Google Vids material covers a short four-scene presentation.
It does not narrate every slide in the 24-slide canonical Items Vision deck.
The retained narrated PPTX is in [`../artifacts/`](../artifacts/README.md).
