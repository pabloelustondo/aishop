# Vision quality benchmark concept

This folder documents incompatible readings of the same dense shelf image.
It motivates a human-verified reference instead of treating one model as truth.

- `031-slide.md` contains the comparison summary.
- `031-notes.md` explains the observed results and limits.
- `031-visual-source.md` records evidence and composition.
- `031-visual.svg` is the authoritative visual.
