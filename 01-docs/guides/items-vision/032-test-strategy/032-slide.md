# Vision Quality and System Reliability Need Different Tests

## Vision quality
- Freeze the source image, prompt, schema, and human-verified reference.
- Change one model, reasoning, context, or image setting at a time.
- Score identification, omissions, counts, inventions, and uncertainty.
- Record latency, usage, cost, retries, and review effort.

## System reliability
- Prove access control, upload, durable progress, and saved evidence.
- Test refresh, refinement, retry, and failure diagnostics.
- For video, preserve frame provenance and prevent duplicate counts.

Release decisions require evidence from both test paths.
