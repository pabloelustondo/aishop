# SDLC2 framework concept

This folder places AI Shop within the twelve-step SDLC2 learning lifecycle.
The concept connects product work with architecture evaluation and evidence.

- `005-slide.md` contains the lifecycle summary.
- `005-notes.md` contains the presenter explanation.
- `005-visual-source.md` specifies the diagram.
- `005-visual.svg` is the authoritative visual.
