# 000 — Visual Source

## Core message
This presentation explains one server-side operation in depth: analysing an
already stored JPEG and preserving the eventual recognition report.

## Composition
Use a minimal 1600 by 900 cover in the AI Shop navy, warm white and green palette.
Set the title large on the left. Put the endpoint directly below it in a restrained
monospace treatment. Use a thin path across the lower third to introduce the
presentation sequence: stored photograph, server run, external GPT, durable report.

The external GPT stage must remain visually outside the AI Shop server boundary in
later architecture slides. The cover only names the sequence and makes no deployment,
quality or performance claim.

## Output
`000-visual.svg`, with editable text and vector paths on a 16:9 canvas.
