# Narrated interactive player

Open [index.html](index.html) in Chrome, Safari, or another browser on the Mac.

Press **Read this slide** once to give the browser permission to speak. It reads
the existing speaker notes and, when enabled, advances through all 30 slides.

Use the previous and next controls or Left and Right arrows to navigate. Space
starts or stops narration. Code and evidence links open in a separate tab.

This player keeps the deck interactive. It does not create a video, upload
content, or replace the Google Vids pilot.

Rebuild `app.js` after editing `tools/content.mjs`:

```sh
node tools/build-player.mjs
```
