# The physical-iPhone session

## Speaker notes

The phone session remains manual and unperformed. Connect the iPhone, choose the diagnostic scheme in Xcode, and run on that device. Tapping the normal app icon does not provide those launch arguments.

Run banana present to completion. Pablo must see a possible match before playback ends and inspect the final report. Repeat with no banana. Export both logs through the share action. Preserve reports and retained images from the app container as well.

Run the Mac gate for matching baseline evidence, then use the comparison command described in the companion runbook. Check for zero dropped frames before comparison.

Record device model, operating system, build, date, and findings. The demonstration and Pablo's committed acceptance record complete a gate that Mac tests cannot replace.
