# The fine-print map

## Speaker notes

The companion walkthrough maps the implementation. Each technical slide has a small set of clickable source, test, or evidence links. The notes explain the meaning before you open those files.

A separate file-coverage index maps changes since the sprint baseline to the relevant subjects. It records exceptions such as original media and unrelated documentation moves. That index is a completeness backstop, not the main explanation.

The maintained slide content also supplies the narration, so the video and written explanation can be revised together. Four subject-based videos keep each review session short. Return to any chapter independently, and pause to inspect the code.
