# Finding a known product

## Speaker notes

Welcome. This walkthrough explains AIShopVision's first foundation: Apple Vision raises a provisional signal while a prerecorded video is still playing.

Need the broader AIShop purpose first? Use the visible product-intent link. It explains the shopper outcome that this technical foundation serves.

Next come two real fixture videos and the HITL journey. The positive fixture contains a banana. The control fixture does not. The system must raise a provisional signal only when its evidence supports it.

The four chapters then cover architecture, frame analysis, episodes and evidence, and verification. The HITL, Human in the Loop, reviews evidence and observes the physical-iPhone run. Live camera capture and general object detection remain outside this sprint.
