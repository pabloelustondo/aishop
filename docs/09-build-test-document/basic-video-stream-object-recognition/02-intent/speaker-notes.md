# Sprint intent

## Speaker notes

The shopper's goal is to know when to pause and inspect a likely target.

We process the stream incrementally instead of waiting for the video to finish.

The user-facing phrase is exactly “possible match”.

A signal is provisional evidence, not confirmation of an object or exact SKU.

The session report retains a best whole frame for every episode.

There is no second pass over the source video when the session stops.

The target must occupy a substantial and recognizable part of the frame.

Candidate-region detection for dense shelves belongs to later work.

This narrow scope lets us test the streaming mechanics with real Vision first.
