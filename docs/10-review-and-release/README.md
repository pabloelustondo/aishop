# Step 10: Review and Release

Store independent review evidence, release-readiness decisions, accepted risks, rollback planning, and explicit human approvals.

Implementation claims are not independent verification, and a green build is not release authorization.

## Manual QA

The [Manual QA Library](manual-qa/README.md) keeps stable test photographs,
expected behavior and dated human execution evidence. A passing QA record may
recommend promotion; Pablo's merge and release decisions remain separate gates.
