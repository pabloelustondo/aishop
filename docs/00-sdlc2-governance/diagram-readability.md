# Diagram Readability

Applies to every project-owned architecture, process, component, sequence, and
evidence-flow diagram, whether Mermaid, PlantUML, SVG, HTML, or exported image.

## Default layout

- Flow diagrams use top-to-bottom direction and vertical scrolling.
- Diagrams must fit the normal document width without horizontal scrolling.
- Use readable labels and a base font of at least 18 px when the format permits.
- Never shrink text merely to force a large diagram onto one screen.
- Place inputs and triggers at the top, processing in the middle, and outcomes
  or evidence at the bottom whenever that ordering matches the system.

## Exceptions and decomposition

A left-to-right layout is allowed only when time or another inherently
horizontal relationship would become less clear vertically. Record that reason
beside the diagram. If either direction becomes crowded, split the content into
an overview plus focused diagrams instead of widening or reducing the font.

## Review gate

Preserve an editable source form. Before approval, render or preview the diagram
at normal document width and verify readable text, unambiguous arrow direction,
no clipped labels, and no required horizontal scrolling.
