# Presentations

## Speaker notes

A presentation is a set of slides prepared for human review under these rules.

The word says nothing about purpose. It names a form, not a subject.

A walkthrough is one type of presentation. Other types will follow.

This folder holds the rules every type shares.

Each type then has its own folder, which adds only what is special to that type.

This folder is itself a presentation, so it is also an example of the form.

It has no type. It follows the shared rules and nothing more.

Agents read this folder before preparing any presentation, of any type.

Status: proposal. It becomes a rule when Pablo commits it.
