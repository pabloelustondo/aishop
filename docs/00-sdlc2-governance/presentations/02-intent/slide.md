# Intent

## Spend Pablo's attention well, whatever the subject

1. **One form for everything presented.** He learns it once and reads every deck the same way.
2. **Meaning on the slide, reasons in the notes, detail in the fine print.**
3. **A presentation can be shown on a screen and spoken.** It is not a document cut into pages.
4. **Types add purpose.** The form stays the same; only the required content changes.
