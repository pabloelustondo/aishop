# Defining a new type

## A type is a governance folder that answers six questions

| Question | The type's rule must say |
|---|---|
| What is it for? | The purpose, and the decision or understanding it serves |
| Who reads it? | The readers, and what each needs from it |
| When is it made, and by whom? | The point in the SDLC2 workflow, and the responsible agent |
| What must it contain? | Required slides and their order, after the title slide |
| What extra checks apply? | Checks added to the shared ones |
| Where do instances live? | The lifecycle step and folder |

The type's folder is itself a presentation, and is the first example of its type.
