# How to check a presentation

## Speaker notes

The author runs these checks before stopping for review.

A reviewer runs them again and does not rely on the author's result.

Most are mechanical. A small script beside the deck can run them.

"Rendered and looked at" is deliberate. A diagram that parses can still be unreadable.

Labels overlap, layouts turn sideways, text shrinks. Only looking finds that.

The line budget applies to Markdown the reader is meant to read.

It does not apply to an SVG file, a log, or a data file.

Fifty lines is an attention budget. If the content does not fit, split the slide.

A type adds checks for its own content. It never removes one of these.

This folder passes these checks. If it stops passing, fix the folder.
