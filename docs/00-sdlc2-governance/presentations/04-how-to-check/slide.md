# How to check a presentation

## Checks every type shares; a type may add its own

| Check | How |
|---|---|
| Two parts per slide | Every numbered folder holds exactly one visual and `speaker-notes.md` |
| Line budget | `wc -l` is at most 50 for every Markdown visual, notes file, and index |
| Index present | `README.md` lists every slide and its notes, in order |
| Links resolve | Run a link check over the folder |
| Fine print present | Every notes file ends with a "Fine print" section |
| Diagrams readable | Top to bottom, legible at normal document width, rendered and looked at |
| Purpose stated | The title-slide notes say who it is for and what it answers |
| Revision named | It states what it describes: a commit, a working tree, or a date |
