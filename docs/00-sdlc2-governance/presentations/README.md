# Presentations

Status: PROPOSAL. It becomes a rule when Pablo commits it and links it from the
[governance index](../README.md). It builds on the
[Reviewability proposal](../reviewability-proposal.md) and on
[Diagram Readability](../diagram-readability.md).

"Presentation" is the parent word: any set of slides prepared for Pablo in the
shared form, whatever its purpose. A type of presentation adds a purpose and the
content that purpose requires. The first defined type is the
[Walkthrough](../good-sprint-walkthroughs/README.md).

This folder is an untyped presentation describing the state of governance on
2026-09-20. It follows its own rules.

## For agents

Read every slide and its notes here before preparing any presentation. Then read
the rule for the type you were asked for. If the type has no rule, follow this
folder only, and say that the type is undefined.
