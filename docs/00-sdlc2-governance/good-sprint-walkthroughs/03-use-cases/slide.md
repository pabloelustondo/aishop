# Use cases

## Who opens a walkthrough, and what they need from it

| Who | When | What they need |
|---|---|---|
| Pablo, reviewing | Sprint implemented, waiting for review | Grasp the design, decide where to dig, accept or ask for changes |
| Independent reviewer agent | Before reading the diff | The implementer's claims, stated so they can be reproduced or refuted |
| Implementing agent | Before building the deck | This folder, as rule and example |
| A later agent or maintainer | Starting the next sprint | The fastest accurate way into the feature |
| Pablo, presenting | Talking it through with someone | Slides for the screen, notes to speak from |
