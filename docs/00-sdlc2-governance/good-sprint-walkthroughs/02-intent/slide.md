# Intent

## The reviewer understands what was built without rebuilding it from the code

1. **Logical architecture first.** Components, flows, interfaces, and meaning.
2. **Code is fine print.** Linked from every slide, never the subject of one.
3. **Honest.** Measured results, limits, and weak spots are on the slides.
4. **Cheap to review.** One idea per slide; notes within a 50-line budget.
