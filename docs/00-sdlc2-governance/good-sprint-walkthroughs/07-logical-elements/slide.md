# What a walkthrough must cover

## Logical elements, not files

| Element | The slide must say |
|---|---|
| Component | Its one responsibility, what it takes in, what it gives out, what it must never do |
| Interface | The contract between two components, in words |
| Flow | The order of events for one scenario, as a diagram |
| Data contract | What each record and field means, and who reads it |
| State | The states of anything that has them, and what moves it between them |
| Rule and reason | Each design decision and why it was made |
| Boundary | What is allowed to depend on what |
| Failure behaviour | What happens when something goes wrong |
