# Good Sprint Walkthroughs

Status: PROPOSAL. It becomes a rule when Pablo commits it and links it from the
[governance index](../README.md).

A Walkthrough is a type of [Presentation](../presentations/README.md). Read that
rule first: the slide unit, the line budget, the shared checks, and the
lifecycle are defined there and are not repeated here.

This folder is a rule and an example at once. It defines the walkthrough deck an
implementing agent prepares when a sprint is implemented and waiting for review.
It is itself built as such a deck.

## For agents

Read every slide and its notes before preparing a walkthrough. Slides 1 to 7 are
the rule. Slides 8 to 16 are patterns, each shown with a real example from iPhone
Sprint 001. Slide 17 is the process. Examples show the pattern; they are not the
record of that sprint, and their links point into its working tree.
