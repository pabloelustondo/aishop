# Good sprint walkthroughs

## Speaker notes

This folder defines the walkthrough an implementing agent prepares for Pablo.

It is used when a sprint is implemented and is waiting for review.

Agents read every slide and its notes here before building a walkthrough.

The folder is also an example. It is built the way it asks you to build.

A walkthrough is a type of presentation. The shared form is defined once, in Presentations.

The running example is iPhone Sprint 001, streaming video candidate recognition.

Examples show the pattern. They are not the record of that sprint.

The idea behind all of it: slides and notes explain the design in the abstract.

Code, tests, and logs are the fine print, one click away when the reader wants it.

Status: proposal. It becomes a rule when Pablo commits it.
