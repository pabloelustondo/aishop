# How to check a walkthrough

## Every shared presentation check, plus five of its own

| Check | How |
|---|---|
| Shared checks pass | Run the checks in [Presentations](../../presentations/04-how-to-check/slide.md) |
| Fixed opening present | Slides 1 to 5 are title, intent, use cases, how to test, high-level architecture |
| Logical elements covered | Compare the deck with the element list on slide 7 |
| Numbers match evidence | Every figure on a slide appears in a linked evidence file |
| Closing present | Measured results, where to look hardest, a runbook if anything is manual |
| Fine-print index complete | Every file changed since the sprint's base commit is mapped or excused |
