# AI Shop — SDLC2 Documentation

This repository is a documentation-only skeleton for managing AI Shop through the twelve-step SDLC2 lifecycle. Each folder owns a distinct class of decisions and evidence.

1. [Context and Domain Analysis](01-context-and-domain-analysis/README.md)
2. [Intent](02-intent/README.md)
3. [System Model and Use Cases](03-system-model-and-use-cases/README.md)
4. [Benchmarks, Test Strategy, and Success Criteria](04-benchmarks-test-strategy-and-success-criteria/README.md)
5. [Viable Proof of Concept](05-viable-proof-of-concept/README.md)
6. [Solution Design and Architecture](06-solution-design-and-architecture/README.md)
7. [Planning](07-planning/README.md)
8. [Specifications as Code](08-specifications-as-code/README.md)
9. [Build and Test](09-build-and-test/README.md)
10. [Review and Release](10-review-and-release/README.md)
11. [Operational Reality](11-operational-reality/README.md)
12. [Observability, Insights, and Learning](12-observability-insights-and-learning/README.md)

Supporting source material belongs in [Reference](reference/README.md).

## Working rule

Documents describe and govern work; they do not authorize implementation, publication, deployment, billing, credentials, or destructive operations by themselves.
