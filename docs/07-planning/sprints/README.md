# Sprint Registry

Register each sprint in its own subfolder. A suggested sprint package contains:

1. approved sprint plan;
2. authorized implementation prompt;
3. agent-delivered scope report;
4. independent integration-test report;
5. independent code-review report;
6. human approval and disposition;
7. correction and evidence subfolders when required.

A draft folder or document does not authorize implementation.
