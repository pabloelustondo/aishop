# Numbered findings — illustrative example

The proposed behavior is one numbered circle per finding, not per physical item.
The matching table gives the number of visible items in that group.

## Sample observation

Source: the left **ANTES** photograph in [screenshot 04](assets/04-hair-before-after.png).
Only the two pale mint-green front-facing bottles on the middle shelf are counted.
Hidden stock and the separate DESPUÉS photograph are excluded.

| Marker | Tentative group | Visible front-row facings | Identification boundary |
|---|---|---:|---|
| 1 | Vitacilina Nutritivo family | 2 | Exact SKU unconfirmed; these may be shampoo and conditioner |

One circle identifies a representative bottle; the other bottle stays unmarked.
This illustrates family-level grouping, not two confirmed units of one catalog SKU.
If their SKUs are confirmed as different, they need separate findings and markers.
This is a selected example, not a complete inventory of the shelf.

## Artifact and evidence boundary

The sample uses built-in image generation, not the AI Shop analysis API.
It is a design mockup: generative editing is not guaranteed to preserve every source pixel.
Use the unchanged source for counting and benchmark evidence, never this derivative.
The production proposal uses deterministic overlays over unchanged originals.
