# Shared Vision Architecture

Three entry paths use related server capabilities for different decisions.

## Current product paths
- AI Shop iPhone scans products to support shopping decisions.
- Web Vision Agent manually accepts shelf photographs and videos for inspection reports.

## Intended integration
- VISTA iPhone would capture shelf evidence during store inspections.

## Shared server foundation
- Secure intake protects access and provider credentials.
- Server processing preserves evidence, tracks work, and obtains AI findings.
- Clients retrieve reports and show uncertainty for human review.

The clients need not use one identical endpoint or return one identical report.
