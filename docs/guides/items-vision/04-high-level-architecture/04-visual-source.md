# 04 - Visual Source

## Message
Three client paths meet a reusable server foundation, while their users and outputs differ.
Make current paths and intended integration visually distinct.

## Composition
Use the established 1600 by 900 light canvas, navy type, and teal accent.
Put three grounded entry examples across the upper half.
Below them, use one responsibility rail rather than a stack of infrastructure boxes.

## Entry examples
AI Shop iPhone: show the existing camera mockup and label it illustrative.
Web Vision Agent: show a recorded QA screenshot with real product evidence.
VISTA iPhone: show an original store-shelf photo; label integration intended.
Do not present the shelf photo as a screenshot from the VISTA app.

## Server rail
Name secure access, media intake, evidence and state, AI processing, and report retrieval.
Use solid connectors for the earlier AI Shop and current web Agent paths.
Use a dashed connector for the intended VISTA iPhone path.
This rail maps responsibilities and does not assert one shared endpoint contract.

## Outcomes
Separate shopper guidance from products, facing counts, and reviewable evidence.
The newer Agent workflow should remain the centre of attention.
