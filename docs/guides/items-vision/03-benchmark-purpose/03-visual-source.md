# 03 - Visual Source

## Core message
AI Shop must improve useful human workflows, not merely produce an AI response.

## Composition
Use a 1600 by 900 canvas with the established light background and navy text.
Place the title at the upper left below the short teal rule.
Show three existing workflows as parallel starting points that converge on one standard.

## Existing workflows
1. Shopping assistance: photograph, provide context, converse, decide.
2. Product identification: inspect labels, packaging, and scene context.
3. Shelf inspection: photograph, record findings, and perform human review.

Use simple line illustrations and short labels rather than interface screenshots.
Connect each workflow to the common evaluation standard with a clean line.

## Common evaluation standard
Use one wide statement at the right:
`Less effort, clearer evidence, preserved human judgment`.

Under it, include three concise measures:
- Fewer actions and less repeated context.
- Faster understanding with honest uncertainty.
- Traceable evidence, findings, corrections, and review.

## Accuracy boundary
Do not claim that the current application already beats these baselines.
This slide defines the comparison that future evidence must support.

## Output
Generate `03-visual.svg` as an editable 16:9 SVG.
Keep every label as SVG text.
