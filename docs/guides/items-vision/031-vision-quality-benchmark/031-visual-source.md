# 031 - Visual Source

## Core message
An accuracy score is meaningful only when the source, reference, and counting contract agree.

## Composition
Use a 1600 by 900 canvas with the established light background and navy text.
Place the title at the upper left below the short teal rule.
Draw one evidence sequence across the centre of the slide.

## Evidence sequence
1. Original shelf image.
2. Human-verified reference inventory.
3. AI result under test.
4. Object-level comparison.

Use simple editable line illustrations for the image, reviewed register, AI report, and comparison.
Connect the four stages with a single restrained line.

## Contract foundation
Add one wide band below the sequence labelled `Counting and identity contract`.
Include these choices:
- Front facings, visible units, or both.
- Family, product, variant, size, or SKU.
- Partial, cropped, unknown, and uncertain handling.
- Source-object links for every reported quantity.

## Evidence warning
Include a visible but quiet note:
`Current GPT reference reports are baselines, not human-approved ground truth.`

Do not show an accuracy percentage because the repository does not support one yet.

## Output
Generate `031-visual.svg` as an editable 16:9 SVG.
Keep every label as SVG text.
