# 02 - Visual Source

## Core message
AI Shop and VISTA serve different decisions through related visual-analysis capabilities.
Both product paths reuse a common server foundation.

## Composition
Use a 1600 by 900 canvas with the established light background and navy text.
Place the title at the upper left below the short teal rule.
Use one continuous composition with two product paths above a shared foundation.

## Left path: AI Shop
Show an iPhone camera used by a shopper.
Label its purpose `Better-informed shopping decisions`.
Show both on-device image processing and server-side analysis.
Label this path `Earlier product path` without implying that it is obsolete.

## Right path: VISTA
Show a store shelf inspection as the user purpose.
Show `Web Vision Agent` as the current manual entry point for photographs and videos.
Show `VISTA iPhone app` with a dashed connection labelled `Intended integration`.
Label the output `Products, visible facings, and reviewable evidence`.

## Shared foundation
Use a single wide band across the lower portion of the slide.
Label it `Common server capabilities`.
Within the band, name secure access, evidence intake, AI coordination, and saved results.
Do not expose individual endpoint names or infrastructure details on this slide.

## Accuracy boundary
Current: AI Shop iPhone path and manual web Agent capabilities described by project evidence.
Intended: end-to-end connection from the separate VISTA iPhone app to the shared analysis path.

## Output
Generate `02-visual.svg` as an editable 16:9 SVG.
Keep every label as SVG text and make current versus intended state immediately visible.
